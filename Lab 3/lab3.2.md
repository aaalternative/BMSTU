# Лабораторная работа: Банковские счета в C++ (Наследование и полиморфизм)

## Описание проекта

Программа на языке **C++**, демонстрирующая базовые принципы объектно-ориентированного программирования (ООП):
- Создание иерархии классов (базовый класс `BankAccount` и производный класс `PrivilegedAccount`).
- Использование спецификатора доступа `protected`.
- Переопределение функций (механизм `virtual` и `override`).
- Статический полиморфизм (через шаблонные функции).
- Динамический полиморфизм (через указатели на базовый класс и виртуальные функции).
- Работу с контейнерами (`std::vector` указателей на базовый класс).

---

## Структура классов

### 1. `BankAccount` (Базовый класс — Простой счет)
- **Поля (`protected`):**
  - `fio` — ФИО владельца (`std::string`)
  - `summa` — начальная сумма счета (`double`)
  - `stavka` — ставка вклада, проценты в год (`double`)
  - `let` — время существования вклада в годах (`double`)
- **Методы:**
  - Конструктор для инициализации полей.
  - `get_total()` — вычисление суммы на счете с учетом начисленных процентов.
  - `print()` — вывод параметров счета в консоль.

### 2. `PrivilegedAccount` (Производный класс — Привилегированный счет)
- **Дополнительные поля (`private`):**
  - `kredit_proc` — процент кредита, предоставляемого по счету (от доступной суммы с учетом времени существования).
- **Переопределенные методы:**
  - `get_total()` — вычисление итоговой суммы с учетом доступного кредита (с вызовом базового метода `BankAccount::get_total()`).
  - `print()` — вывод параметров счета (с вызовом базового метода `BankAccount::print()`).

---

## Реализация полиморфизма

1. **Статический полиморфизм:** реализован с помощью шаблонной функции `print_static(T obj)`, которая вызывает метод печати на этапе компиляции.
2. **Динамический полиморфизм:** реализован через виртуальные функции (`virtual`) и функцию `print_dynamic(BankAccount* acc)`, принимающую указатель на базовый класс.
3. **Вектор указателей:** в функции `main` создается `std::vector<BankAccount*>`, объединяющий разные типы счетов, что позволяет вызывать методы в цикле и суммировать общие средства полиморфно.
