## Описание программы
Программа создает вектор структур `Department` (Подразделение: название, ФИО начальника, число сотрудников, число сотрудников в отпуске) и умеет сохранять его в текстовый и бинарный файлы, а также считывать обратно.

## Структура проекта
Проект лежит в папке `lab 2`:
- `main.cpp` — исходный код программы (написан просто и понятно).
- `readme.md` — инструкция.

## Инструкция по запуску

1. **Компиляция программы:**
   ```bash
   g++ main.cpp -o lab
   ```

2. **Запись данных в файлы:**
   Создает встроенный массив из 3-х подразделений и сохраняет:
   ```bash
   ./lab -w text data.txt
   ./lab -w bin data.bin
   ```

3. **Чтение данных из файлов:**
   Читает из файлов и выводит на экран:
   ```bash
   ./lab -r text data.txt
   ./lab -r bin data.bin
   ```

4. **Сравнение размеров файлов:**
   ```bash
   ./lab -compare data.txt data.bin
   ```

## Выводы
Бинарный файл обычно занимает меньше места, так как числа сохраняются в машинном виде (ровно 4 байта на int), а не как текст. Текстовый файл больше по размеру, но зато его можно открыть и прочитать в любом текстовом редакторе.
