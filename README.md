## Условие задачи

Для заданных a и p вычислить 

$$ x = \sqrt[n]{a} $$

по рекуррентному соотношению Ньютона:

$$ x_{n+1} = \frac{1}{p} \left[ (p-1)x_n + \frac{a}{x_n^{p-1}} \right]; x_0 = a $$

Сколько итераций надо выполнить, чтобы для заданной погрешности x=10-2, 10-4, 10-6 выполнялось соотношение: 

$$ |x_{n+1} - x_n| \leq \varepsilon $$


### Решение 

В работе необходимо представить программную реализацию алгоритма с использованием **трех видов циклов**:
* `while` (цикл с предусловием)
* `do-while` (цикл с постусловием)
* `for` (параметрический цикл с принудительным выходом при выполнении критерия)


### Ручной расчет 

**Дано:** \(a = 27.0\), \(p = 3\)
